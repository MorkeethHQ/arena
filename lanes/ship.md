# Ship lane stock pack

**Clock:** 20 minutes  
**Tiebreak:** clearer hierarchy

## Sealed task

Build one offline `index.html` landing page for a fictional product named
Patchbay, which turns messy team requests into owned work. Include a hero,
three concrete benefits, one proof block, and one primary call to action. Use
only inline CSS and system fonts; no build step or network requests.

## Rubric

- The declared file exists and opens locally.
- “Patchbay” and a clear one-sentence value proposition are visible.
- Exactly one primary call to action is visually dominant.
- Three distinct, concrete benefits and one proof block are present.
- No external network assets, tracking, or build step.
- The layout remains readable at 390px.
- The fighter supplied the exact path and a one-sentence shipping claim.

**DQ:** missing/unreadable artifact or any external network asset.
